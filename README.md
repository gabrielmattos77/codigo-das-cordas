# 🎸 Código das Cordas

### Plataforma de ensino de violão e teoria musical

O **Código das Cordas** é um projeto educacional desenvolvido para ajudar estudantes de violão a compreender não apenas como tocar, mas também **como a música funciona**.

A proposta é apresentar os conteúdos de forma organizada e progressiva, partindo dos fundamentos da teoria musical até conceitos utilizados na construção de acordes, escalas, harmonia e improvisação.

## ✨ Principais recursos

- 📚 Conteúdo organizado por módulos
- 🎸 Aulas de violão e teoria musical
- 🧠 Conceitos apresentados de forma progressiva
- 🎼 Estudos de acordes, escalas e harmonia
- 🎵 Conteúdos relacionados à improvisação
- 🔒 Sistema visual de aulas bloqueadas
- 📱 Interface responsiva
- 💬 Integração com WhatsApp
- 📄 Materiais de estudo em PDF
- 🎨 Identidade visual própria
